# Lumina: Where Stories Connect 🌟

Lumina is a full-stack blogging platform built with Node.js, Express, and MongoDB, adhering strictly to **Clean Architecture** principles.

## 🏗️ Architecture & Features

- **Layered Architecture**: Organized into `domain`, `application`, `presentation`, and `persistence` layers.
- **Design Patterns**: Implements Singleton database connection pattern and Repository pattern.
- **Security**: Authentication powered by JWT, salted password hashing, and custom authorization middleware.
- **Frontend**: Clean HTML/JS interfaces for Home, Blogs, About, Contact, Sign In/Sign Up, and Blog Management Dashboard.
